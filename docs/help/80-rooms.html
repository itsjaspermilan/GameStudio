Big levels: rooms, tiles and the camera

The Glow43 screen is 256x192 pixels. A level can be much bigger, and the camera decides which part of it you see. A room is a data file in rooms/ that describes a level: how big it is, its background, its tile layers, and which entities start where. gs.load_room("arena") builds it.

Rooms or layouts? A scene's layout holds the same data and is built when the scene starts, so for a new level that is all you need: set its size to Bigger: it scrolls on the layout's Layout tab. A room is for when one scene builds levels from code, picking which one to load (gs.load_room("level" .. n)). Both open in the same layout editor. The list on the left shows Rooms once a game has one: make the first with + under Other files (rooms/arena.lua), or with Make this game below.

A room file

A room is plain Lua that returns a table, so you can write it by hand or generate it. Entities are { name, x, y } (an optional fourth value is a table of values to set).

return {
  width = 640, height = 480,           -- bigger than the screen: the camera will scroll
  background = "#14234f",
  entities = {
    { "walker", 320, 240 },
    { "tree", 100, 100 }, { "tree", 520, 90 }, { "tree", 300, 380 },
    { "tree", 80, 400 },  { "tree", 560, 420 }, { "tree", 450, 250, { size = 14 } },
  },
}

The layout editor

Click a room in the list and it opens in the layout editor, the same one scenes use (a room with code in it, like a local or a sum, opens as text instead). Select picks things up and moves them, Tiles paints the chosen layer (Shift-click fills, right-click picks a tile up, Alt-click erases), Things places the entity chosen on the right, and Paths draws routes. The size (on the Layout tab) is the camera's limits; the dashed box shows one screen. Saving writes the same plain data you see here, so you can always switch to Edit as text.

Paths

A path is a list of points in the room, for a guard's patrol or a platform's route. Draw it in the layout editor, or write it in the room file:

paths = {
  patrol = { { 40, 40 }, { 280, 40 }, { 280, 200 }, loop = true },
},

An entity walks it with self:follow_path("patrol", 60) (60 pixels a second). A path that does not loop ends by calling the entity's on_path_end; self:stop_path() stops early. gs.path("patrol") gives the points if you want to use them yourself.

The things in it

local Tree = gs.entity{
  size = 10,
  depth = 5,
}

function Tree:draw()
  gs.draw.rect(self.x - 2, self.y, 4, self.size, "#9a5324")
  gs.draw.circle(self.x, self.y - 2, self.size, "#2f8a3f")
end

return Tree
local Walker = gs.entity{
  speed = 100,
}

function Walker:update(dt)
  local dx, dy = gs.input.dir()
  self.x = gs.clamp(self.x + dx * self.speed * dt, 8, 632)
  self.y = gs.clamp(self.y + dy * self.speed * dt, 8, 472)
end

function Walker:draw()
  gs.draw.circle(self.x, self.y, 7, "#ffa38c")
end

return Walker

The camera

gs.load_room already tells the camera the size of the level, so it never shows the empty space outside. All that is left is whom to follow. smooth is how lazily the camera catches up (0 is stiff, 0.1 a little soft, 0.3 floaty). gs.camera:shake(amount, seconds) is for hits and explosions; gs.camera:set(x, y) moves it directly (for a cutscene).

local Main = gs.scene{}

function Main:enter()
  gs.load_room("arena")
  gs.camera:follow(gs.first("walker") or gs.spawn("walker", 320, 240), { smooth = 0.1 })
end

function Main:draw_ui()
  gs.draw.text("THE ARENA IS 640x480", 8, 6, "#ffffff")
end

return Main

Things the camera cares about: anything drawn in draw of an entity is in world coordinates, so it scrolls. Anything drawn in a scene's draw_ui (and an entity with screen = true) is in screen coordinates and stays put, like a score.

Zoom. gs.camera.zoom = 2 shows the world twice as big (a quarter of it fits on the screen); the camera still keeps to the level's edges. Whole numbers keep pixel art crisp. draw_ui is never zoomed, so the score stays the same size. Going to another scene puts the zoom back to 1.

Tile layers

Real levels are made of tiles drawn in the tileset editor: a picture sheet where each tile is 8, 16 or 32 pixels square. A layer is a grid of tile numbers (counting from 0, left to right then down; -1 is empty). Add layers in a room file, or by hand with gs.add_layer:

-- in rooms/arena.lua
layers = {
  { tileset = "ground", depth = 100, data = {
      { 0, 0, 1, 0 },
      { 0, 1, 1, 0 },
    } },
  -- a far-away layer that moves at half the camera's speed and repeats sideways
  { tileset = "clouds", depth = 90, scroll_x = 0.5, wrap_x = true, data = { { 0, 1, 2, 1 } } },
},

A layer is drawn from one picture that the engine builds once, so a big map costs almost nothing per frame. Ask a layer what is at a spot with gs.tile_at(layer, x, y) (for walls and floors), and change it with gs.set_tile. Glow43 allows four tile layers in a room. Names go with the files: "ground" is tilesets/ground.json.
