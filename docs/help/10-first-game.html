Your first game: Star Catcher

Stars fall from the top. Slide a basket left and right to catch them. Miss three and the game starts again. It is five small files, and each one is one idea. Press Make this game at the bottom to get all of it as a ready-made game, or make a new game and type the files in yourself.

1. The game file

game.lua says what the game is called, which console it is made for (the console decides the screen size, colours and limits) and which scene starts first.

return gs.game{
  title = "Star Catcher",
  console = "glow43",            -- 320x240, the Glow43 handheld
  start = "scenes.main",      -- the file scenes/main.lua
}

2. The player

Each kind of thing in the game is an entity: one file in entities/ that ends with return. The table in gs.entity{ ... } holds its starting values. tags are names you use to find and collide things. The hitbox is the area that counts as touching: { x, y, width, height }, measured from the entity's position.

The engine calls update every step (60 times a second) with dt, the seconds since the last step. Moving by speed * dt makes the speed the same on every machine. Until you draw a sprite for it, you can draw an entity yourself in a draw method.

-- The player: a basket that slides left and right.
local Player = gs.entity{
  tags = { "player" },
  hitbox = { -16, -6, 32, 12 },
  speed = 160,                       -- pixels a second
}

function Player:update(dt)
  local dx = gs.input.dir()          -- -1 for left, 0 for still, 1 for right
  self.x = gs.clamp(self.x + dx * self.speed * dt, 16, 304)
end

function Player:draw()
  gs.draw.rect(self.x - 16, self.y - 6, 32, 12, "#ffa38c")
end

-- A method named on_collide_ runs when this entity touches something with that tag.
function Player:on_collide_star(star)
  local state = require "lib.state"
  state.score = state.score + 1
  star:destroy()
end

return Player

3. The stars

Every entity has vx and vy, its speed in pixels a second. The engine moves it for you, so a star only needs a downward speed. create runs once when the entity is made.

local state = require "lib.state"

local Star = gs.entity{
  tags = { "star" },
  hitbox = { r = 6 },                -- a circle with a radius of 6
}

function Star:create()
  self.vy = 70 + gs.random(0, 40)    -- falls at a slightly different speed each time
end

function Star:update(dt)
  if self.y > 250 then               -- fell past the bottom: a life lost
    state.lives = state.lives - 1
    self:destroy()
  end
end

function Star:draw()
  gs.draw.circle(self.x, self.y, 6, "#ffd08a")
end

return Star

4. Shared state

Several files need the score and lives, so they live in one small file that any of them can load with require. Lua loads a file once and gives everybody the same table.

local M = { score = 0, lives = 3 }

function M.reset()
  M.score, M.lives = 0, 3
end

return M

5. The scene

A scene is a screen of your game. enter runs when it starts and is where you create things. update runs every step. draw_ui draws on top of everything, fixed to the screen: the place for the score.

local state = require "lib.state"

local Main = gs.scene{}

function Main:enter()
  state.reset()
  gs.spawn("player", 160, 220)       -- the name of the file in entities/, and where to put it
  self.next_star = 0
end

function Main:update(dt)
  self.next_star = self.next_star - dt
  if self.next_star <= 0 then
    gs.spawn("star", gs.random(10, 310), -10)
    self.next_star = 0.8
  end
  if state.lives <= 0 then
    gs.goto_scene("scenes.main", { fade = 0.4 })    -- start over with a fade
  end
end

function Main:draw_ui()
  gs.draw.text("SCORE " .. state.score, 8, 6, "#ffffff")
  gs.draw.text("LIVES " .. state.lives, 248, 6, "#ffffff")
end

return Main

Things to try

  • Run the game, then change 0.8 to 0.3 in scenes/main.lua and save. The stars come faster, and the game kept running.
  • Draw a sprite for the star in the sprite editor, name it star, add sprite = "star" to the entity's table and delete its draw method.
  • Make a sound effect called catch and play it with gs.sfx("catch") in on_collide_star.
  • Make some stars worth more: give them a points value in the table and use star.points in the player.
