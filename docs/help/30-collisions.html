Collisions and tags

Games are mostly about things touching things. GameStudio makes that short to write: give entities tags, and write a method called on_collide_<tag> on the one that cares. This page builds "Space Pop": fly a ship, shoot drifting rocks.

Tags and hitboxes

A tags = { "enemy" } list gives every entity of that kind the tag. An entity has a hitbox if you give it one (hitbox = { x, y, w, h } from its position, or { r = radius } for a circle) or if it has a sprite (then the sprite's collision box is used). Entities without a hitbox never collide.

When two hitboxes overlap, the engine calls on_collide_tag(other) on any entity that has such a method, for every overlapping entity with that tag. The engine only checks pairs somebody asked about, so a method you never write costs nothing.

The ship

gs.input.pressed("a") is true for exactly one step when A goes down. gs.spawn returns the entity it made, and its third argument can set values on it: here the bullet's starting speed.

local state = require "lib.state"

local Ship = gs.entity{
  tags = { "ship" },
  hitbox = { -7, -7, 14, 14 },
  speed = 130,
}

function Ship:update(dt)
  local dx, dy = gs.input.dir()
  self.x = gs.clamp(self.x + dx * self.speed * dt, 8, 248)
  self.y = gs.clamp(self.y + dy * self.speed * dt, 8, 184)
  if gs.input.pressed("a") then
    gs.spawn("bullet", self.x, self.y - 8)
  end
end

function Ship:draw()
  gs.draw.rect(self.x - 7, self.y - 7, 14, 14, "#4f9bf0")
  gs.draw.rect(self.x - 2, self.y - 11, 4, 5, "#a8d4ff")
end

-- a rock hit the ship
function Ship:on_collide_rock(rock)
  rock:destroy()
  gs.camera:shake(4, 0.2)
  state.hits = state.hits + 1
end

return Ship

The bullet

set_velocity(angle, speed) sets vx and vy from a direction. Angles are in degrees clockwise: 0 is right, 90 is down, 180 is left, 270 is up. Bullets that leave the screen must be destroyed, or they pile up forever.

local Bullet = gs.entity{
  tags = { "bullet" },
  hitbox = { -2, -4, 4, 8 },
}

function Bullet:create()
  self:set_velocity(270, 260)        -- straight up
end

function Bullet:update(dt)
  if self.y < -10 then self:destroy() end
end

function Bullet:draw()
  gs.draw.rect(self.x - 2, self.y - 4, 4, 8, "#ffd08a")
end

function Bullet:on_collide_rock(rock)
  rock:hurt(1)
  self:destroy()
end

return Bullet

The rock

Entities can have their own methods. rock:hurt(1) above calls this one. Every rock has the same methods, and each keeps its own hp.

local state = require "lib.state"

local Rock = gs.entity{
  tags = { "rock" },
  hitbox = { r = 9 },
  hp = 2,
}

function Rock:create()
  self.vy = gs.random(25, 55)
  self.vx = gs.random(-20, 20)
end

function Rock:hurt(amount)
  self.hp = self.hp - amount
  if self.hp <= 0 then
    state.score = state.score + 10
    self:destroy()
  end
end

function Rock:update(dt)
  if self.y > 210 then self:destroy() end
end

function Rock:draw()
  gs.draw.circle(self.x, self.y, 9, self.hp == 1 and "#ffa38c" or "#8a90a8")
end

return Rock

The scene and the shared score

The ship and the rocks both change the score, so it lives in a small shared file (see Your first game).

local M = { score = 0, hits = 0 }

function M.reset()
  M.score, M.hits = 0, 0
end

return M
local state = require "lib.state"

local Main = gs.scene{}

function Main:enter()
  state.reset()
  self.next_rock = 0.5
  gs.spawn("ship", 128, 170)
end

function Main:update(dt)
  self.next_rock = self.next_rock - dt
  if self.next_rock <= 0 then
    gs.spawn("rock", gs.random(10, 246), -10)
    self.next_rock = 0.6
  end
end

function Main:draw_ui()
  gs.draw.text("SCORE " .. state.score, 8, 6, "#ffffff")
  gs.draw.text("HITS " .. state.hits, 200, 6, "#ffa38c")
end

return Main

Finding things

You often need an entity that you did not just create. Tags are how you find them:

CallGives you
gs.first("ship")The first entity with the tag (or nil).
gs.count("rock")How many there are.
gs.each("rock", function(r) ... end)Runs a function for each.
gs.nearest(x, y, "rock", 120)The closest one within 120 pixels.
gs.in_radius(x, y, 50, "rock")A list of those within 50 pixels (an explosion).
self:touching("wall")The first wall overlapping this entity right now, for checks outside a collide method.
self:distance_to(other), self:angle_to(other)For chasing and aiming. self:move_toward(other, 60) sets the speed toward it.

Try: make a turret entity that shoots the nearest rock. Every second it does local rock = gs.nearest(self.x, self.y, "rock", 150), and if there is one, spawns a bullet and calls bullet:set_velocity(self:angle_to(rock), 220).

Why tags and not names? The code in the ship does not need to know about every kind of rock you add later. Give a new BigRock the tag "rock" and everything already works.
