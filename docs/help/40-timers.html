Timers, tweens and coroutines

Games are full of "in two seconds, do this". You could count down in update, and sometimes that is right. For the rest, GameStudio has four tools. All of them stop by themselves when the entity (or scene) that made them goes away, so you never get a timer that fires on something that no longer exists.

ToolUse it for
self:after(seconds, fn)Once, later: remove a bullet, end a power-up, show a message.
self:every(seconds, fn)Again and again: spawn, shoot, blink.
self:tween({ x = 100, alpha = 0 }, 0.5, "out_quad")Change numbers smoothly: slide, fade, grow.
self:go(function() ... gs.wait(1) ... end)A little script that reads top to bottom and can pause: cutscenes, boss attack patterns.

The same four exist on gs (gs.after, gs.tween...) for a scene to use. Each returns a timer you can stop with timer:cancel(). Easings are linear, in_quad, out_quad, in_out_quad, in_cubic, out_cubic, in_out_cubic, out_back and out_bounce.

A small light show

This orb blinks on a timer, floats up with a tween, then a coroutine fades it out and removes it.

local Orb = gs.entity{
  tags = { "orb" },
  color = "#ffd08a",
}

function Orb:create()
  -- every half second, flip between two colors
  self.lit = true
  self:every(0.5, function() self.lit = not self.lit end)

  -- float up over 2 seconds, slowing down at the end
  self:tween({ y = self.y - 80 }, 2, "out_quad")

  -- a script: wait, then fade out, then go away
  self:go(function()
    gs.wait(1.5)
    self:tween({ alpha = 0 }, 0.5)
    gs.wait(0.5)
    self:destroy()
  end)
end

function Orb:draw()
  local r, g, b = gs.color(self.color)
  gs.draw.circle(self.x, self.y, 8, { r, g, b, math.floor(255 * self.alpha) })
  if self.lit then gs.draw.circle(self.x, self.y, 3, "#ffffff") end
end

return Orb

A coroutine is an ordinary function that may call gs.wait(seconds) (or gs.wait_until(function() return something end)) to pause. The game goes on while it waits, and it continues exactly where it stopped. That makes sequences easy to read, compared with a pile of timers and flags.

local Main = gs.scene{}

function Main:enter()
  -- the scene runs its own script: spawn an orb, wait, spawn another...
  gs.go(function()
    for i = 1, 3 do
      gs.spawn("orb", 60 + i * 80, 180)
      gs.wait(0.7)
    end
    gs.wait(3)
    gs.goto_scene("scenes.main")           -- and again
  end)
end

function Main:draw_ui()
  gs.draw.text_centered("LIGHT SHOW", 20, "#8a90a8")
end

return Main

Tips

  • Use dt in update for steady movement; use timers for events. Both are measured in real seconds, however fast the machine is.
  • A timer made by an entity is cleaned up when it is destroyed. A gs.after made in a scene lasts until the scene changes.
  • Tweening x or y while the entity also has a vx makes them fight. Pick one.
  • For a repeating enemy pattern a coroutine in a loop (while true do ... gs.wait(1) end) is often clearer than a state machine.
