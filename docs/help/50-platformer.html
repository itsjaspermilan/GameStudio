A platformer

Run, jump, and follow the hero across a level wider than the screen. The first version of anything is simple: this one moves in two small steps and steps back if it ended up inside a block. It is easy to read, and it is good enough for a lot of games.

The level, as text

A level can be a picture made of letters. Each # is a block. It is easy to see and to edit, and when you want tiles with art you can switch to a tile layer (see Big levels) without changing the rest of the game.

A block

Blocks only need a tag and a hitbox. The hitbox starts at the block's position: { 0, 0, 16, 16 }.

local Block = gs.entity{
  tags = { "block" },
  hitbox = { 0, 0, 16, 16 },
}

function Block:draw()
  gs.draw.rect(self.x, self.y, 16, 16, "#6b5a14")
  gs.draw.rect(self.x, self.y, 16, 3, "#6ccf4f")
end

return Block

The hero

The engine can move an entity by vx and vy on its own, but for a platformer you want to move it yourself and undo the move if it hit something, so this entity keeps its own vertical speed in dy. self:touching("block") asks: is anything with that tag overlapping me right now?

  1. Move sideways. If that put us inside a block, undo it.
  2. Add gravity to dy, move up or down. If that put us inside a block, undo it; if we were falling, we are standing on something.
  3. If we are standing and A was pressed, jump: a strong upward speed.
local Hero = gs.entity{
  tags = { "hero" },
  hitbox = { -6, -14, 12, 14 },      -- the position is at the feet
  speed = 110,                       -- pixels a second
  jump = 300,
  gravity = 800,                     -- pixels a second, every second
  dy = 0,
  grounded = false,
}

function Hero:update(dt)
  -- 1. sideways
  local dx = gs.input.dir()
  self.x = self.x + dx * self.speed * dt
  if self:touching("block") then self.x = self.x - dx * self.speed * dt end
  if dx ~= 0 then self.flip = dx < 0 end

  -- 2. gravity
  self.dy = self.dy + self.gravity * dt
  self.y = self.y + self.dy * dt
  self.grounded = false
  if self:touching("block") then
    self.y = self.y - self.dy * dt
    if self.dy > 0 then self.grounded = true end
    self.dy = 0
  end

  -- 3. jump
  if self.grounded and gs.input.pressed("a") then
    self.dy = -self.jump
  end

  -- fell out of the world: start again
  if self.y > 300 then self.x, self.y, self.dy = 40, 100, 0 end
end

function Hero:draw()
  gs.draw.rect(self.x - 6, self.y - 14, 12, 14, "#ffa38c")
  local eye = self.flip and self.x - 4 or self.x + 1
  gs.draw.rect(eye, self.y - 11, 3, 3, "#000000")
end

return Hero

The scene

The scene reads the level and makes a block for every #, then tells the camera to follow the hero. bounds keeps the camera inside the level. smooth makes it lag a little, which feels good.

local level = require "lib.level"

local Main = gs.scene{}

function Main:enter()
  for row, line in ipairs(level) do
    for col = 1, #line do
      if line:sub(col, col) == "#" then
        gs.spawn("block", (col - 1) * 16, (row - 1) * 16)
      end
    end
  end
  local hero = gs.spawn("hero", 40, 100)
  gs.camera:follow(hero, { smooth = 0.1, bounds = { 0, 0, 640, 240 } })
end

function Main:draw_ui()
  gs.draw.text("{left}{right} MOVE, {a} JUMPS", 8, 6, "#ffffff", 1, { shadow = true })
end

return Main

The screen behind everything is black. A layout can set a background color (see Big levels), or draw a big rectangle from an entity with a high depth (bigger numbers are drawn further back).

Improving it

  • Variable jump height. When A is released while going up, cut the speed: if self.dy < 0 and not gs.input.held("a") then self.dy = self.dy * 0.5 end.
  • Coyote time. Let the hero jump for 0.1 seconds after walking off a ledge: remember when it was last grounded and compare.
  • Enemies. Give them the enemy tag and a Hero:on_collide_enemy handler. Tell stomping from being hit by checking self.dy > 0 and self.y < enemy.y.
  • Fast things. If something moves more than its own size in one step it can pass through a block. Move it in a few smaller steps.
